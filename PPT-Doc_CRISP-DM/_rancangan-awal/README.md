# Rancangan awal (arsip)

Dokumen di folder ini adalah rancangan CRISP-DM mingguan yang disusun sebelum implementasi
(kuesioner ±45 butir, clustering, klasifikasi tiga level, aturan asosiasi, 10 alternatif × 7 kriteria,
deployment Gradio). Sistem yang akhirnya dibangun berbeda: regresi Random Forest + SMART 8 kriteria
dan 5 alternatif, deployment Streamlit. Dokumen fase terbaru di folder induk menjelaskan sistem
yang dibangun; ide yang belum dibangun dicatat sebagai pengembangan lanjutan.

Berkas .pptx mingguan di folder induk juga mengikuti rancangan awal ini.
